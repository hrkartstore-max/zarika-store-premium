# Zarika Store Premium

A responsive Next.js storefront for Indian ethnic wear and jewellery. Built with Next.js 15, React 19 and TypeScript.

## Local development

```bash
npm install
npm run dev
```

## Production validation

```bash
npm run typecheck
npm run build
```

## Deploy

Import this repository in Vercel and keep the Root Directory set to `.`. This demo checkout does not process real payments; connect a server-side order backend and payment provider before accepting live orders.
